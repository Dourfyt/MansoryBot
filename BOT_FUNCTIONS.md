# Mansory Bot — назначение и функции

## Назначение бота

**Mansory Bot** — Telegram-бот для учёта чеков и связки групп «клиенты ↔ проверяющие»:

- **Группы клиентов** — отправляют фото чеков на проверку.
- **Группы проверяющих** — подтверждают или отклоняют чеки, вводят суммы, ведут учёт по курсу и проценту удержания.

Бот хранит чеки, курсы обмена и проценты по каждой группе (отдельная БД на группу), считает оборот и выплаты за день, обрабатывает ссылки на транзакции Tron и может рассылать сообщения по всем группам. Управление связями и часть настроек доступны админам в личке и через веб-панель.

---

## Роли групп

- **Клиент** — группа, из которой отправляют фото чеков командой `/п`; чеки уходят в связанную группу проверяющих.
- **Проверяющий** — группа, в которую приходят фото чеков; здесь нажимают «Подтвердить»/«Фейк», вводят сумму командой `/чек <сумма>` и видят статистику.
- **Несвязанная группа** — обычная группа с собственной БД; доступны команды учёта без связки с другой группой.

Связи «клиент ↔ проверяющий» задаются админом в личке (`/connect`) или через админ-панель.

## Команды в группах

### Группа клиентов (роль `client`)

| Команда | Описание |
|--------|----------|
| `/п` | Отправить фото чека на проверку (сообщение должно содержать фото). Фото пересылается в связанную группу проверяющих с кнопками «Подтвердить» / «Фейк/Нету». |
| `/инфо` | Показать статистику по группе: последние чеки, оборот за сегодня, суммы к выплате и т.д. |
| `/помощь` | Краткая справка по командам. |

### Группа проверяющих (роль `verifier`)

| Команда | Описание |
|--------|----------|
| Кнопки под фото | «✅ Подтвердить» — чек принят, затем ввод суммы через `/чек <сумма>`. «❌ Фейк/Нету» — отклонить чек. |
| `/чек <сумма>` | Добавить чек с указанной суммой (после подтверждения фото). Сумма привязывается к последнему подтверждённому фото в этой группе. Поддерживается отрицательная сумма, например `/чек -50`. |
| `/инфо` | Статистика: последние 15 чеков за сегодня, дефолтный курс/процент, сумма чеков по категориям, оборот за сегодня, к выплате, уже выплачено, остаток. |
| `/помощь` | Справка по командам. |

### Любая группа (в т.ч. несвязанная)

| Команда | Описание | Ограничения |
|--------|----------|-------------|
| `/инфо` | Последние 15 чеков за сегодня + оборот, к выплате, выплачено, остаток. | — |
| `/чеки_сегодня` | Все чеки за текущий день в виде таблицы (ID, время, сумма, курс, процент, сумма в валюте, к выплате). | — |
| `/помощь` | Список команд с учётом роли группы. | — |
| `/дефолт <курс> <процент>` | Установить курс и процент по умолчанию для чата. Вместо значения можно `-`. Примеры: `/дефолт 93.5 10`, `/дефолт 92.8 -`. | Только админ чата |
| `/пкп <курс> <процент> <ID_чека>` | Присвоить конкретному чеку свой курс и процент. | Только админ чата |
| `/отвязать_курс <ID_чека>` | Убрать привязку курса у чека (будет использоваться дефолт). | Только админ чата |
| `/отвязать_процент <ID_чека>` | Убрать привязку процента у чека. | Только админ чата |
| `/удалить_чек <ID>` | Удалить чек по ID. | Только админ чата |
| `/выплата <сумма>` | Зафиксировать выплату на указанную сумму за сегодня. | Только админ чата |
| `/сброс` | Сбросить все данные группы: чеки, настройки, курсы, проценты, выплаты. Таблица обработанных Tron-транзакций не очищается. | — |
| `/курс` | Сообщение о том, что управление курсами через эту команду отключено; используется `/дефолт`. | — |
| `/процент <число>` | Установить «процент чата» в настройках (trader_rate). | — |

### Callback-кнопки (под сообщениями)

- **confirm_receipt** / **fake_receipt** — подтверждение или отклонение фото чека в группе проверяющих.
- После подтверждения под сообщением отображается «✅ Проверено» и т.п.; кнопки редактирования курса/процента через интерфейс отключены (используются команды `/дефолт`, `/пкп`, `/отвязать_курс`, `/отвязать_процент`).

## Обработка сообщений (не команды)

- **Ссылки TronScan и хеши транзакций**  
  Если в сообщении есть ссылка вида `https://tronscan.org/#/transaction/<hash>` или отдельный 64-символьный hex-хеш, бот:
  - запрашивает данные транзакции через API;
  - проверяет, что в транзакции фигурирует глобальный адрес кошелька из настроек;
  - извлекает сумму (TRC20 и т.п.);
  - не обрабатывает один и тот же хеш дважды (хранится в общей БД);
  - при успехе добавляет чек в БД текущей группы с полученной суммой и отправляет ответ в чат.

Глобальный адрес кошелька и список обработанных транзакций хранятся в `group_connections.db` (общая БД менеджера связей).

## Команды в личке (приватный чат с ботом)

Доступны только пользователям из списка админов бота.

| Команда | Описание |
|--------|----------|
| `/start` | Приветствие и список команд управления связями. |
| `/connect <chat_id_клиентов> <chat_id_проверяющих>` | Связать группу клиентов с группой проверяющих. Одна группа проверяющих может быть связана с несколькими группами клиентов. |
| `/disconnect <chat_id_клиентов> <chat_id_проверяющих>` | Разорвать связь между указанными группами. |
| `/list` | Список всех активных связей: по каждой группе проверяющих перечислены группы клиентов и ID. |
| `/stats` | Статистика: всего связей, активных, неактивных, уникальных групп клиентов и проверяющих. |
| `/peer_id` | Работает только в группе: выводит ID группы и её роль (клиент/проверяющий/не связана). |
| `/update_group_id <старый_id> <новый_id>` | Обновить ID группы в связях и в именах файлов БД (например, после перевода в супергруппу). |
| `/help` | Справка по командам управления. |

Не-админам в личке при `/start` показывается приветствие и «актуальные ссылки», заданные в админ-панели (если настроены); иначе — сообщение об отсутствии прав.

## Планировщик (scheduler)

Задачи запускаются по расписанию (UTC):

| Время (UTC) | Задача | Описание |
|-------------|--------|----------|
| **23:59** | `reset_all_databases` | Сброс данных по всем группам: очистка чеков, настроек, курсов, процентов, выплат в каждой `data_group_*.db`. Обработанные Tron-транзакции не удаляются. |
| **21:30** | `send_daily_info_if_receipts` | По каждой группе (файлам `data_group_*.db`) проверяется, есть ли чеки за текущий день. Если есть — в эту группу отправляется ежедневная сводка (аналогично `/инфо`): чеки за день, оборот, к выплате, выплачено, остаток. Используется общий алгоритм отправки с несколькими ботами и повторами. |
| **06:50** | `send_morning_sticker` | Отправка утреннего стикера во все чаты с задержками и повторными попытками. |

## HTTP-сервер на боте (порт 8765)

Внутри процесса бота поднимается локальный HTTP-сервер для запросов от админ-панели:

| Метод и путь | Назначение |
|--------------|------------|
| **POST /broadcast** | Рассылка текста по всем группам из списка рассылки (список строится из `data_group_*.db`). Тело: `{"text": "...", "exclude_chat_ids": [...]}`. Используется тот же алгоритм отправки, что и в планировщике (несколько ботов, повторы); при постоянных ошибках (кик, блок, chat not found) чат помечается как недоступный. |
| **POST /broadcast/check-availability** | Проверка доступности групп: для каждого чата из списка рассылки вызывается `get_chat`, при успехе сохраняется название в БД, при ошибке доступа чат добавляется в список недоступных и исключается из рассылки. |
| **GET /broadcast/inactive-groups** | Возвращает список `chat_id` групп, в которых за текущий календарный день не было ни одного чека (по таблице `receipts` в соответствующей `data_group_*.db`). Используется в панели для кнопки «Исключить неактивные» в рассылке. |

## Админ-панель (Next.js)

Веб-интерфейс для управления связями, рассылкой и общими настройками. Работает с той же БД `group_connections.db` и при необходимости дергает бота по HTTP.

- **Связи**  
  Просмотр активных связей (группы клиентов/проверяющих), добавление новых, деактивация и удаление связей по одной или массово (выбор галочками: деактивировать выбранные / удалить выбранные). Восстановление неактивных связей (массово или по одной). Редактирование ID групп.

- **Неактивные связи**  
  Список деактивированных связей с возможностью вернуть или удалить их (по одной или массово).

- **Ручная рассылка**  
  Ввод текста и выбор групп-исключений; отправка через POST на бота `/broadcast`. Есть поиск по названию/ID группы, кнопки «Проверить доступность» и «Исключить неактивные» (группы без чеков за текущий день).

- **Приветствие и актуальные ссылки**  
  Настройка текста и кнопок-ссылок, которые показываются не-админам в личке при `/start`.

- **Кошелёк**  
  Глобальный адрес кошелька Tron для проверки входящих транзакций (хранится в `global_settings`).

Данные для рассылки (список чатов, недоступные, названия) хранятся в таблицах `broadcast_chats` и `broadcast_inaccessible` в `group_connections.db`; при старте бот обновляет список чатов из папки `databases/` (`data_group_*.db`).

---

## Хранение данных

- **databases/group_connections.db** — общая БД: связи групп (connections), глобальные настройки (кошелёк, приветствие, ссылки), обработанные Tron-транзакции (processed_transactions), список чатов для рассылки (broadcast_chats, broadcast_inaccessible).
- **databases/data_group_<chat_id>.db** — своя БД на каждую группу: чеки (receipts), настройки (settings), курсы (exchange_rates), проценты (retention_rates), выплаты (payouts).

Роли групп (клиент/проверяющий) определяются по связям в `group_connections.db`; одна и та же группа не может быть одновременно клиентом и проверяющим.

## Краткое резюме по функциям

1. **Связка групп** — клиенты отправляют фото чеков, проверяющие подтверждают/отклоняют и вводят суммы.
2. **Учёт чеков** — по каждой группе: чеки, курс, процент, оборот за день, к выплате, выплачено, остаток.
3. **Tron** — обработка ссылок и хешей транзакций, проверка по глобальному кошельку, добавление чека в группу.
4. **Ежедневная автоматика** — сброс данных в 23:59 UTC, рассылка сводки по группам с чеками в 21:30 UTC, утренний стикер в 06:50 UTC.
5. **Рассылка** — ручная рассылка из панели по всем группам с исключениями и проверкой доступности/неактивности.
6. **Админка** — связи, неактивные связи, рассылка, приветствие и ссылки, кошелёк; массовые операции со связями.
